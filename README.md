# AI News Aggregator

An automated AI News Aggregator platform utilizing FastAPI for the backend and a modern frontend interface. It leverages CrewAI and MCP for intelligent news gathering and summarization.

## Project Structure

- `backend/`: FastAPI application handling the news aggregation pipeline, CrewAI orchestration, and API endpoints.
- `frontend/`: Real-time user interface for displaying trending topics, progress tracks, and aggregated news.

## Deployment

The backend is configured for deployment on Render, and the overall system is equipped with necessary Docker configurations for portability.
